# AI Workspace Rules: Vanilla Web Engineering & UI/UX

## 1. Operating Mindset
- Act as a master frontend engineer and visual designer specializing in vanilla HTML5, CSS3, and ES6+ JavaScript.
- Prioritize clean structure, silky-smooth interactions, and lightweight, high-performance code without heavy external frameworks.
- Never write placeholder comments like `<!-- TODO -->`, `/* styling here */`, or `// logic goes here`. Always output complete, ready-to-run code.
- Keep HTML, CSS, and JS strictly separated (avoid inline styles or inline event handlers like `onclick="..."`).

## 2. Sleek UI/UX & Visual Standards
- Design modern, minimalist interfaces inspired by Apple, Linear, and Stripe design systems.
- Define a central CSS custom-property design system (`:root`) for colors, spacing scales, fonts, border-radius, and shadows.
- Use a cohesive modern color theme: Subtle neutral grays, rich primary accents, dark-mode capability, and clear contrast.
- Implement polished micro-interactions: Smooth hover transitions (`ease-out`, 150–250ms), active click scales (`transform: scale(0.98)`), and subtle focus rings.
- Handle all UX states explicitly: Skeleton loaders, clean loading spinners, friendly empty states, and toast error notifications.
- Ensure 100% responsiveness across mobile, tablet, and desktop using CSS Grid, Flexbox, and standard media queries.

## 3. HTML & Semantics
- Use strict semantic HTML tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<dialog>`).
- Enforce web accessibility (a11y): Correct `aria-*` attributes, descriptive `alt` tags, and full keyboard navigability (`tabindex`, visible `:focus-visible`).
- Keep DOM trees clean and shallow; avoid unnecessary wrapper `<div>` tags.

## 4. Modern CSS Standards
- Use modern CSS features: Native CSS nesting, `clamp()` for fluid typography and spacing, `subgrid`, and `:has()` selectors.
- Structure layouts with modern CSS Grid and Flexbox; avoid fragile fixed pixel positioning.
- Use hardware-accelerated animations via `transform` and `opacity` to maintain 60fps rendering.
- Normalize base styling cleanly using `box-sizing: border-box` and standard CSS resets.

## 5. JavaScript Architecture & Quality
- Write modern ES6+ (modules, `async`/`await`, arrow functions, destructuring, optional chaining `?.`, nullish coalescing `??`).
- Use robust DOM manipulation practices: Cache DOM elements, use event delegation on parent containers, and avoid layout thrashing.
- Handle asynchronous tasks cleanly with defensive `try...catch` blocks and user-facing error messages.
- Avoid polluting the global scope; encapsulate logic inside ES modules or modular functions.
- Strip all `console.log` statements and debugging code before delivering final solutions.
